# .knowledge

Project-local memory. Everything here is specific to **this** project.

| File | Holds |
|---|---|
| `project.md` | What it is, scope, current state, how to run it |
| `architecture.md` | Components, boundaries, data model, known weaknesses |
| `requirements.md` | Functional / non-functional requirements, constraints, assumptions |
| `roadmap.md` | Now / Next / Later / Ideas / Done |
| `progress.md` | Reverse-chronological progress log |
| `decisions.md` | Project-scoped decisions with rationale |
| `sessions/` | One log per working session |

**Routing rule:** if a piece of knowledge would help a future *unrelated* project, it does
not belong here — it belongs in `AI-Memory/`. When in doubt, write it here and promote it
later once a second project proves it generalises.
