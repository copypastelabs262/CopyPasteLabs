# Product Platform

**Empty by design. Nothing here yet, deliberately.**

This is the system colleges would eventually use. Its design already exists —
[`.knowledge/architecture.md`](../.knowledge/architecture.md) — and it is bound by the full
Engineering Constitution and every one of the nine obligations in
[`.knowledge/capture-contract.md`](../.knowledge/capture-contract.md).

## Why it is empty

Per the 2026-07-30 platform-separation decision, the Product Platform is **not** what the Lab
grows into. It is a separate system, designed *from evidence the Lab produced*. The named
failure mode of that decision is the Experiment Platform quietly becoming the product; an
empty directory with a stated gate is the cheapest guard against it.

## The gate

Code enters this directory only when **Stage C** opens — see
[`.knowledge/roadmap.md`](../.knowledge/roadmap.md). That requires, in order:

1. The walkthrough has run and its results document exists.
2. The domain model has survived it, or has been simplified until it does.
3. Research numbers exist and are reproducible by one command (Constitution VII).

Until all three are true, the correct contents of this directory are this file.

Opening the gate is a written Decision in
[`.knowledge/decisions.md`](../.knowledge/decisions.md), not a judgement call made while
someone is mid-task.
