# Drop Teams screenshots here

Put your Microsoft Teams (and optionally Google Classroom) screenshots in THIS folder —
any filename, PNG or JPG. They feed the class-shell IA spec (`../grammar.md`).

The shots that matter most, per the 2026-09-02 discussion:

1. Class list — left rail + team cards ("my classes")
2. Inside one class — the General/Posts stream ("what's new")
3. Assignments tab — the list, plus ONE open assignment (teacher view if possible;
   the creation form is the thing our confirm-queue replaces)
4. Activity feed ("something needs me")
5. The chat composer — how the input bar anchors to the bottom
6. Mobile — 2–3 phone screenshots of the same class

Name them anything; if you can hint the surface in the filename
(e.g. `assignments-teacher.png`, `mobile-stream.jpg`), even better.
