# Glossary

Shared vocabulary. When a term means something specific at CopyPasteLabs, define it here
so it means the same thing to everyone.

**AI-Memory** — the global, cross-project knowledge base at `E:\CopyPasteLabs\AI-Memory`.

**BuilderOS** — the operating charter governing how sessions produce and preserve knowledge.

**Decision** — an intentional engineering choice recorded with its rationale, alternatives,
and trade-offs. Distinct from a Learning: a Decision is a commitment, a Learning is a fact.

**Demote** — move knowledge from AI-Memory back into a single project's `.knowledge`
because it turned out not to generalise.

**Learning** — a reusable engineering concept. Must be true independent of any one project.

**Mistake** — a recorded failure with its cause and prevention. Written without blame; the
purpose is the prevention line.

**Pattern** — a reusable architecture or workflow. Bigger than a snippet, smaller than a
framework.

**Project knowledge** — the `.knowledge/` directory inside a project. Holds only
project-specific state; nothing permanent lives here.

**Promote** — move a project-local learning into AI-Memory once it proves reusable.

**Session** — one working conversation. Ends with a knowledge update, always.

**Snippet** — reusable code small enough to paste, with enough context to adapt.
